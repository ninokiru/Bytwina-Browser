# Hướng dẫn sử dụng (bản thử)

- **Mở trang:** gõ địa chỉ hoặc từ khóa vào ô địa chỉ, nhấn Enter.
- **Tab:** ＋ để mở tab mới; × để đóng; 📌 để ghim (tab ghim nằm đầu).
- **Nhóm tab:** gõ tên nhóm vào ô "Nhóm tab" khi đang ở tab đó, nhấn Enter.
- **Tìm tab:** nút ⊞.
- **Lưu trang:** ☆ (dấu trang), 🔖 (danh sách đọc).
- **Tải xuống:** file tải về nằm trong thư mục Downloads; xem danh sách bằng nút ⤓.
- **Riêng tư:** nút 🕶 để bật/tắt. Khi bật, trang không vào lịch sử (cookie vẫn lưu).
- **Xóa dữ liệu:** Cài đặt ⚙ → "Xóa dữ liệu duyệt web".
- **Phím tắt:** Ctrl+T, Ctrl+L, Ctrl+R, Alt+←/→, Esc (dừng tải). Chỉ hoạt động khi tiêu điểm ở thanh công cụ.

## Hạn chế hiện tại
- Trang http không mã hóa bị chặn (trừ localhost), xem ADR-011.
- Cần WebView2 Runtime (thường có sẵn trên Windows 10/11).
